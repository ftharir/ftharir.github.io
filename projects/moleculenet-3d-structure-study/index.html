Overview

Models that predict molecular properties from 3D structure are usually tested on geometries computed with quantum chemistry. Everyday datasets only contain a SMILES string per molecule, so the 3D structure has to be generated, and a generated structure is an approximation. The lab task: build several kinds of 3D structure so that a structure-based model (PVD, pre-training via denoising) can be evaluated on each of them.

This project does the generation part for three MoleculeNet datasets and adds a compact experiment that asks whether the structure type changes prediction quality.

Approach

  1. 1

    Approximate structure

    Hydrogens are added and a 3D conformer is embedded with RDKit, with a fixed seed so the result is reproducible.

  2. 2

    Optimised structure

    The approximate structure is relaxed with the UFF force field.

  3. 3

    Flat graph structure

    A 2D layout with every z coordinate set to 0: the molecule drawn on paper, as a control without 3D information.

  4. 4

    Export and audit

    Three SDF files per dataset (5,046 molecules in total), and a report of what failed: invalid SMILES, molecules that cannot be embedded, UFF runs that do not converge.

  5. 5

    Compare

    Geometry descriptors of each structure type plus an ECFP4 baseline, a Random Forest, scaffold and random splits, five seeds, ROC-AUC.

Key decisions

A fixed seed

Embedding is random; a fixed seed makes every run produce identical structures.

Failures are data

Invalid or unprocessable molecules return None and are counted, not dropped silently.

A common set of molecules

All structure types are compared on exactly the same molecules and labels.

Balanced scaffold split

The CSV files are ordered by label, so scaffold groups are shuffled instead of taken in file order.

Limitations, stated openly

  • The structure types are statistically hard to tell apart in this proxy experiment, even the flat z = 0 structure: global descriptors and a Random Forest are far less sensitive to atom positions than a model like PVD.
  • PVD itself was not run (it needs its pre-trained checkpoint and a GPU), and there is no exact reference structure for these datasets.
  • One conformer per molecule.

What is next

  • Fine-tune PVD on each structure type with the same splits and a no-pre-training control.
  • Add an exact-structure condition with a dataset that has computed geometries, such as QM9.
  • Generate several conformers, use MMFF for drug-like molecules and raise the UFF iteration limit.
