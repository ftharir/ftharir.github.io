Overview

Early notebooks usually report one accuracy number. The playbook keeps six of mine exactly as they were, written while I was learning machine learning, and puts a more rigorous analysis next to each: several models, cross-validation, leak-free preprocessing and error analysis.

It covers classification, regression, NLP and computer vision, and each project has a README that states the original and the follow-up result side by side.

Approach

  1. 1

    Keep the original

    Each project's first notebook stays untouched, so the starting point is visible.

  2. 2

    Re-evaluate

    An analysis notebook re-runs the problem with better methodology and metrics.

  3. 3

    Compare models

    Several models per problem with fixed seeds and cross-validation instead of one train/test split.

  4. 4

    Prevent leakage

    Imputation, scaling and encoding live inside scikit-learn pipelines fitted on training data only.

  5. 5

    Explain

    Confusion matrices, residuals, per-region errors, feature importances and misclassified examples.

Key decisions

Metrics that match the problem

Recall for malignant tumours, spam and heart-disease cases instead of accuracy alone; RMSE and MAE next to R².

Honest caveats

Small samples, capped targets and duplicated rows are stated in every README.

Reproducibility

Fixed seeds, dependency files and notebooks that ship with their outputs.

Limitations, stated openly

  • These are learning projects on small public datasets; the follow-ups improve the evaluation more than the models.
  • Helmet detection recalls only 16 % of riders without a helmet, and the heart-disease model's ROC-AUC is a modest 0.723; both are reported as they are.
